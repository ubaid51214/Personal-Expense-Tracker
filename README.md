# Personal Expense Tracker
A responsive web-based Personal Expense Tracker built using HTML, CSS, and Vanilla JavaScript. This application helps users manage their daily income and expenses, organize transactions, and monitor their overall financial activities.

## Features
### Dashboard
- Displays Total Balance, Total Income, Total Expenses, and Total Transactions.
- Automatically updates summary cards when transactions change.

### Transaction Management
- Add new income and expense transactions.
- Enter transaction title, amount, category, date, and description.
- Edit existing transactions.
- Delete transactions with confirmation.

### Search and Filters
- Search transactions by title and other relevant information.
- Filter transactions by type (Income or Expense).
- Filter transactions by category.
- Display a message when no matching transactions are found.

### Sorting
- Newest First
- Oldest First
- Low to High
- High to Low
- Overall transaction order

### Data Persistence
- Uses browser Local Storage to save transaction records.
- Data remains available after refreshing the page.
- Uses JSON to convert and retrieve stored data.

### Responsive Design
- Responsive layout for desktop and mobile devices.
- CSS media queries for different screen sizes.
- Mobile-friendly dashboard, forms, filters, and transaction history.
